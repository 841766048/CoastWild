# 通信加解密模块 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 实现与服务端协议一致的 AES-256-ECB 请求加密、响应解密和密钥派生。

**Architecture:** 纯 Foundation/CommonCrypto 值类型，无网络和全局状态依赖；密钥派生与 JSON 密码学处理分离。

**Tech Stack:** Swift、CommonCrypto、XCTest。

## Global Constraints

- 标准密钥用 ASCII `0` 右补至 32 字节。
- 风控密钥只接受 16/24/32 字节，不补齐。
- 使用 PKCS7Padding，输出/输入为 Base64 文本。
