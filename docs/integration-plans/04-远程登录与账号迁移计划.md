# 远程登录与账号迁移 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 接入设备快捷登录、自动登录和 H5 后台登录。项目尚未上线，原有本地账号和数据均为测试数据，不执行迁移。

**Architecture:** `RemoteSessionCoordinator` 管理有限状态机；`DeviceIdentityStore` 管理 UserDefaults/Keychain UUID；本地账号不自动写入服务端。

**Tech Stack:** Swift Concurrency、Security、XCTest。

## Global Constraints

- 远程账号替换本地账号体系；旧测试账号和测试数据不迁移。
- UUID Keychain 可访问级别为 `afterFirstUnlockThisDeviceOnly`。
- 退出登录同时清理内存与持久化会话。
