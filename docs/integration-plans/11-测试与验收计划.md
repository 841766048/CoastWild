# 测试与验收 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 建立可重复的单元、集成、StoreKit、WebView、UI 和真机验收证据。

**Architecture:** Swift Package 负责纯 Swift 测试，Xcode test target 负责 UIKit/WebKit/StoreKit，UI target 负责用户链路。

**Tech Stack:** XCTest、XCUITest、URLProtocol、StoreKit Configuration、xcodebuild。

## Global Constraints

- 每个缺陷修复先增加可重现测试。
- 不使用真实生产账号、商品或归因 Token 运行自动测试。
- 验收记录包含命令、设备、OS、时间和结果。

---

### Task 1: 测试矩阵

**Files:** Create `docs/integration-test-matrix.md`; Modify `Package.swift`, `project.yml` as needed.

- [ ] 将配置、密码学、API、登录、WebView、Bridge、IAP、归因的成功/失败路径映射到测试。
- [ ] 验证每条必选需求至少有一条自动测试。

### Task 2: 可重复验证命令

**Files:** Create `scripts/verify_integration.sh`.

- [ ] 实现串行执行 `swift test`、`xcodebuild test`、模拟器构建和发布配置扫描。
- [ ] 任一子步骤失败时保留原始退出码。

### Task 3: 真机验收

**Files:** Create `docs/integration-verification.md`.

- [ ] 验收 Keychain、相册、通知、ATT、WebView 媒体、购买和恢复。
- [ ] 记录无网络、弱网、前后台、进程回收和重启结果。
