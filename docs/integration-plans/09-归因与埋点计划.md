# 归因与埋点 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在用户同意和实际投放需求下接入 ATT、Adjust/Facebook 及服务端归因上报。

**Architecture:** `AttributionCoordinator` 依赖 SDK adapter，先请求 ATT，再启动允许的 SDK；归因快照可持久化并有 30 秒兜底。

**Tech Stack:** AppTrackingTransparency、Adjust SDK、Facebook SDK、XCTest。

## Global Constraints

- 未同意跟踪不影响主要功能。
- SDK Token 由正式配置提供。
- 事件不包含不必要的个人数据。
