# 账号注销与隐私合规 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让退出、本地数据清除和永久注销成为三个可区分、可验证的用户操作。

**Architecture:** `AccountDeletionService` 先请求服务端删除，成功后清理会话、Keychain 和账户数据；法务文本通过现有 `LegalDocument` 展示。

**Tech Stack:** UIKit、Security、XCTest。

## Global Constraints

- 注销前显示不可逆后果并二次确认。
- 存在订阅时必须提示单独取消 Apple 订阅。
- 隐私文本必须与实际 SDK 和数据传输一致。
