# 环境配置与发布配置 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 建立类型安全、可测试、不会将测试值带入正式包的对接环境配置。

**Architecture:** `IntegrationEnvironment` 从 Info.plist 读取非敏感配置，运行时覆盖由专用配置解析器输出。发布校验器拒绝空值、非 HTTPS 和已知测试标识。

**Tech Stack:** Swift、Foundation、XCTest、XcodeGen。

## Global Constraints

- 保持 `PRODUCT_BUNDLE_IDENTIFIER` 由 Xcode 配置提供。
- 不在源码中提交私密 Token。
- 正式环境只允许 HTTPS。
