# iOS 对接总计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在保留现有 UIKit 原生产品的前提下，完成合法合规的远程配置、加密 API、账号、H5、Bridge、IAP 和归因对接。

**Architecture:** 对接能力作为独立 `Integration` 模块加入工程，通过协议与现有 `CoastEnvironment` 集成。本地学习 WebView 与远程业务 WebView 保持隔离。

**Tech Stack:** Swift 5、UIKit、Foundation、Security、CommonCrypto、WebKit、StoreKit 2、XCTest。

## Global Constraints

- 最低系统保持 iOS 17.0，除非产品明确要求降低。
- 正式值不从示例工程复制，必须来自项目配置。
- 不实施针对审核人员的隐藏界面、绕过开关或误导性切换。
- 不开启全局 ATS 明文网络；最小化权限与 SDK。
- 新行为必须经过失败测试、最小实现和完整回归。
