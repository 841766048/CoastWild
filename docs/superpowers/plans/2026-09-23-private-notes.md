# 设备匿名身份笔记同步实施计划

用户已确认 Keychain UUID + Firebase 匿名身份方案，理解不保证重装/换机恢复。当前 codex/native-uikit 原工作区继续实施，不改签名或内购分支。

1. UUID 以 Keychain 为准，旧 Defaults 缓存仅用于首次迁移；先修改身份测试验证旧行为失败。
2. 使用 FirebaseCore、FirebaseAuth、FirebaseFirestore，注册真实 Bundle ID。仅启用匿名认证，不启用收费存储。
3. 笔记路径 users/{uid}/devices/{deviceUUID}/accounts/{accountHash}/notes/{noteID}。账号散列用于本机账本分区，不声称它经过业务服务器验证；安全边界为 Firebase UID。
4. CoastLedger 持久化待同步笔记 ID。正常 commit 原子保存正文与待同步队列。删除保留待同步 ID，直到服务器确认删除。迁移旧账本时现有笔记入队。
5. 同步先处理本地队列，再读取服务器，读取期间发生的本地修改优先。账号切换后旧结果不得应用；失败保留队列，网络恢复和前台重试。私有图片不上传，本地图片引用不发送云端。
6. 云端仅存标题、正文、日期、草稿、标签；行程关联、图片、来源草稿关联暂为本地字段。服务器返回内容合并时保留本地关联。
7. 规则仅允许所有者读写，校验字段、长度、标签、文档 ID、设备 UUID，测试拒绝未认证、跨 UID、额外字段和超长内容。
8. 删除账号先暂停同步，删除当前账号分区云端笔记，成功才删除本地；失败可重试，不伪装成功。
9. 运行 Swift 回归、规则模拟器测试、模拟器构建。不得仅以配置部署成功宣称端到端功能可用。

公共课程迁移仍属后续独立检查点，此次先完成用户新增的私有笔记身份与同步。
