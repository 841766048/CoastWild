# 第三方日期选择器实施计划

Goal: 按用户要求通过 CocoaPods 接入 BRPickerView，替换日期/时间手输，沿用现有 UIKit 表单与双语。

- [x] UI回归先验证点击日期必须显示选择器，不弹键盘；取消不改值、可选日期清空、确认回填、手记日期必填。
- [x] 接入 BRPickerView/DatePicker 3.x，封装统一主题、语言、日期序列化与可选清空。
- [x] 出游起止日期、手记日期、活动时刻与已定日期行程的天数选择接入；保留现有日期范围及持久化校验。
- [x] workspace构建、Core测试和UI回归；记录版本与截图。

日期保存 yyyy-MM-dd，时刻 HH:mm。日期计算使用 Gregorian/UTC，默认“今天”按内容地区计算，避免时区转换导致跨日。开始/结束选择范围受另一端约束；取消不写入，确认触发已有草稿逻辑。只改原生工程，不改Figma/H5。
