# 本地模拟账号注销设计

## 目标

在尚无服务端注销 API 的阶段，为 App 提供可区分、可验证的退出登录、清除本地空间和注销账号流程。注销流程使用可注入的模拟网络请求；不得宣称已经删除服务端数据。

## 操作边界

- 退出登录只清除当前远程会话，保留该账号的本地账本和照片。
- 清除本地空间删除当前账号的账本和照片，并退出登录；不影响其他账号。
- 注销账号先执行模拟网络请求。请求失败时不清除会话、账本或照片；请求成功后删除当前账号的本地账本和照片，再清除远程会话并返回登录页。
- 注销不删除设备身份。设备身份属于安装级标识，不等同于账号数据，后续真实服务端接口可以继续使用它建立新会话。
- 注销确认文案明确说明操作不可恢复，并提醒 Apple 订阅需要在系统订阅管理中单独取消。

## 架构

核心模块新增 `AccountDeletionService`。它依赖三个窄接口：模拟远程注销请求、本地账号数据清理、会话清理。服务严格按“远程成功 → 本地账号清理 → 会话清理”的顺序执行。

模拟远程接口在生产构建中只提供短暂异步延迟并返回成功；UI 测试可通过启动参数切换为失败，用于验证错误恢复。该接口不构造虚假的 URL、请求参数或响应 DTO，避免形成未经确认的服务端契约。

`CoastStore` 提供删除当前账号持久化账本的方法。照片目录由 App 层在注销事务中清理。服务完成后，`CoastEnvironment` 激活空账号并返回登录根页面。

## 界面

账号页保留“退出登录”，并新增“注销账号”。数据与隐私页保留“清除本地空间”。三个入口使用稳定的无障碍标识供 UI 测试区分。

注销账号使用二次确认弹窗，正文说明：本地行程、手记、收藏和学习进度将永久删除；当前阶段仅模拟网络注销；Apple 订阅不会自动取消。确认后按钮进入不可重复提交的加载状态。失败时关闭加载状态、保留页面数据并展示可重试错误；成功后返回登录页。

## 合规文本与入口

中英文隐私政策和用户条款应与当前实现一致，列明远程账号、安装级设备标识、远程 H5、未来支付及归因能力、数据保存范围、注销方式和联系方式。尚未启用的能力必须写为未启用或计划接入，不得描述为已经收集。

首启隐私页、登录页和设置页都必须能够打开隐私政策与用户条款。远程 URL 不可用时继续使用随包本地文本。

## 错误处理

- 模拟远程失败：整个事务停止，本地数据保持不变。
- 本地账本或照片删除失败：不清除会话，向用户显示错误，允许重试。
- 会话清理发生在本地数据成功删除之后。会话存储当前清理操作不抛错，因此不会留下“数据已删但仍处于登录态”的可恢复错误分支。
- 重复点击由界面加载状态和服务执行状态共同阻止。

## 测试

- 单元测试验证模拟远程失败时账本与会话均未清除。
- 单元测试验证成功时严格依次调用远程、本地、会话清理。
- 单元测试验证本地清理失败时不清除会话。
- Core 存储测试验证只删除当前账号文件，其他账号不受影响。
- UI 测试验证三个独立入口、注销说明、二次确认、加载状态、失败提示和成功返回登录页。
- 法务文档测试验证中英文文件存在且包含账号、设备标识、H5、支付、归因、保留期、注销和联系方式等主题。

## 后续真实接口迁移

服务端提供正式注销 API 后，只替换模拟远程接口实现并补充请求契约测试；注销事务、本地清理、界面和失败恢复保持不变。正式发布检查必须阻止仍使用模拟注销实现的构建。
