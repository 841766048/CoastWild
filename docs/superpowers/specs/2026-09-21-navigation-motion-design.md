# 页面跳转动效设计规格

## 目标

统一海岸与山野的页面导航动效，让层级关系清楚、响应迅速，并保持 HF-v1 克制、自然的 iOS 原生手感。

## 动效规则

### 层级页面

- Push：新页面从右侧进入，当前页面向左轻移；总时长 0.28 秒。
- Pop：与 Push 反向运动；总时长 0.24 秒。
- 使用非弹性减速曲线，点击后立即产生位移，不添加模糊、旋转或缩放。
- 保留系统屏幕左缘侧滑返回；取消交互返回时平滑回到原位置。

### Tab 切换

- Tab 内容不横向滑动，避免暗示不存在的父子层级。
- 新 Tab 内容使用 0.18 秒淡入，并伴随最多 6pt 的轻微上移复位。
- 首次展示根页面不播放动画；连续快速切换时从当前状态继续，不重复闪烁。

### 弹窗与确认框

- 自定义确认框由中心以 0.96 比例放大到 1.0，同时淡入；0.22 秒。
- 关闭时淡出并回到 0.98；0.16 秒。
- 遮罩和弹窗使用相同时长及曲线，防止两层不同步。
- 系统照片选择器、日期选择器和系统 Action Sheet 保留系统自身转场。

## 动效参数

- Push：0.28 秒，`UIView.AnimationCurve.easeOut` 对应的非弹性曲线。
- Pop：0.24 秒，方向反转。
- Tab：0.18 秒，透明度 0 → 1，位移 y=6 → 0。
- Dialog Open：0.22 秒，透明度 0 → 1，缩放 0.96 → 1。
- Dialog Close：0.16 秒，透明度 1 → 0，缩放 1 → 0.98。
- 所有导航动画允许用户交互并从当前动画状态接续。

## 无障碍

- `UIAccessibility.isReduceMotionEnabled == true` 时，Push、Pop 和 Tab 不产生空间位移。
- 减少动态效果下，Tab 与弹窗仅使用不超过 0.12 秒的淡入淡出；导航可直接切换。
- 动画不得阻断 VoiceOver 焦点更新或改变控件可点击范围。

## 实现边界

- 动效由统一的导航控制器、Tab 控制器和自定义弹窗承载，业务控制器不逐页复制动画代码。
- 不修改页面布局、字体、颜色、业务数据或跳转路径。
- 直接调用 `pushViewController`、`popViewController`、`setViewControllers` 的现有流程统一纳入规则。
- 登录后根控制器切换保持即时完成，避免认证状态切换时短暂显示旧页面。

## 验收

- 探索、学习、出游、手记与个人空间的二级页面 Push/Pop 方向一致。
- 系统侧滑返回可交互、可取消，不出现黑屏、白闪或导航栏错位。
- 四个 Tab 切换时不横向滑动，快速切换无叠影。
- 自定义提示和确认框的背景遮罩与内容同步出现、同步关闭。
- 开启减少动态效果后，所有空间位移动画关闭。
- 现有中英文 UI 自动化流程、键盘、照片选择器和日期选择器不受影响。
