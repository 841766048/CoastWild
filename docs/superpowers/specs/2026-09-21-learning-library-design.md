# 学习资料库与双详情设计规格

## 目标

将“学习”扩展为冲浪、徒步、露营三个分类，每类 15 篇、合计 45 篇双语资料。文章在同一列表展示，但通过 JSON 中的 `detailType` 分流到 Web 长文详情或 UIKit 原生步骤详情。所有列表与详情读取均经过统一模拟网络请求，并展示第三方 Loading 动效。

## 内容分配

每个分类包含 8 篇 Web 长文和 7 篇原生步骤课。

### 冲浪

Web：第一次冲浪前需要知道的 7 件事、读懂浪况与潮汐、识别离岸流、选择第一块冲浪板、防寒衣与脚绳、冲浪礼仪、选择正规课程、冲浪后的装备养护。

原生：认识冲浪板、基础划水、俯卧起身、下水前热身、安全摔落、搬板与入水、下水前安全检查。

### 徒步

Web：第一次海岸徒步准备、读懂路线难度、天气高温与雷电、离线地图与导航、饮水与路餐、无痕山林、野生动物与蜱虫、迷路与紧急处置。

原生：基础打包、选择徒步鞋、三层穿衣、使用登山杖、认识步道标识、找到合适步频、徒步后恢复。

### 露营

Web：第一次露营规划、选择营地、帐篷系统、睡眠系统、营地烹饪与用火、食物保存与动物、风雨天气应对、无痕露营与废弃物。

原生：搭建帐篷、装填背包、建立营地厨房、净水步骤、头灯与夜间安全、撤收营地、紧急检查表。

## JSON 模型

`catalog.json` 保留 `lessons` 顶层数组。每篇文章共有：

- `key`：跨语言稳定 ID。
- `category`：`surf`、`hike`、`camp`。
- `detailType`：`web` 或 `native`。
- `title`、`summary`、`group`：`en` 与 `zh-Hans`。
- `heroImage`：Asset Catalog 图片名。
- `icon`：SF Symbol 名称。
- `readingMinutes`、`level`、`tags`。
- `sourceLinks`：来源标题、URL、机构名称。

Web 条目使用 `webDetail`：作者、更新时间、重点摘要、目录、结构化正文区块、图解、提示、清单、引用、来源和下一篇 ID。正文区块支持 `paragraph`、`image`、`callout`、`diagram`、`checklist`、`steps`、`quote`。

原生条目使用 `nativeDetail`：步骤数组，每步含标题、正文、图片、SF Symbol 图标与可选提示。Web 条目的 `nativeDetail` 为 `null`，原生条目的 `webDetail` 为 `null`；解码后执行类型与载荷一致性校验。

## 页面行为

学习列表延续 HF-V1 的页头、分类按钮和大图卡片。卡片增加详情类型图标、阅读时间、难度和标签。点击 Web 条目进入 `WKWebView`，由本地结构化 JSON 渲染响应式 HTML；点击原生条目进入 UIKit 步骤详情，保留进度记录。

Web 页严格按已确认的手机版设计：393pt 视口、白底、深海蓝、沙色强调、16pt 横向边距、吸顶导航、图片与图解、资料来源、继续学习入口。所有外部来源链接在 `SFSafariViewController` 打开，正文自身不依赖联网。

## 模拟网络与 Loading

新增 `LearningRepository`，使用 `async throws` 提供分类列表和详情，默认延迟 650–1100ms。UI 测试启动参数可将延迟设为 0。错误使用稳定枚举 `LearningRequestError`，支持测试失败态。

Loading 使用 CocoaPods `SkeletonView`。学习列表显示匹配实际卡片结构的骨架；Web 和原生详情显示页头及正文骨架。请求期间禁止重复触发，成功后淡出骨架，失败后显示重试按钮。Reduce Motion 下禁用骨架滑动，只显示静态占位。

## 内容与版权

文字为项目原创整理，不复制来源原文。安全信息以 NOAA/NWS、NPS、Leave No Trace 等机构公开资料交叉核对，并在每篇文章保存来源链接。图片只使用项目自有、已生成或明确可用的本地资源；图标使用 SF Symbols 或项目现有图标，不直接抓取第三方图片。

## 验收标准

- JSON 恰好包含 45 篇：每类 15 篇，每类 8 Web、7 原生。
- 中英文标题、摘要和正文非空；图片、图标、来源字段完整。
- Web 与原生载荷不会混用，列表能正确分流。
- 三类列表、两类详情均经过模拟请求并出现 Loading。
- 请求失败可重试，快速切换分类不会显示旧请求结果。
- 原生课程进度继续持久化；Web 文章可滚动、收藏/分享入口可用。
- iOS 17+ 构建、核心测试和 UI 回归通过。
