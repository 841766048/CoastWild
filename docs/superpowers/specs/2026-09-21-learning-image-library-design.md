# 学习资料双层图片库设计规格

**日期：** 2026-09-21  
**范围：** 学习模块 45 篇资料（冲浪、徒步、露营各 15 篇）

## 目标

为每篇学习资料建立与主题内容对应的独立视觉资源，替换目前 45 篇内容重复复用 8 张通用图片的状态。列表和详情头图使用写实户外摄影风格，详情中的知识点与步骤使用 HF-V1 柔和纪实插画。

## 视觉体系

### B：写实封面

- 每篇资料生成 1 张独立横向封面，共 45 张。
- 场景、天气、装备和人物动作必须直接对应文章主题。
- 保持自然光、低饱和海蓝与灰绿色调，人物呈现真实户外状态。
- 不生成文字、Logo、水印、夸张运动姿势或危险示范。
- 横向构图需要兼容列表裁切与详情头图，主体避开最外侧 12% 安全区。

### A：HF-V1 教学插画

- 每篇资料至少生成 1 张独立教学插画，共 45 张。
- 使用米白背景、海蓝、灰绿和暖沙色，轻质感、清晰轮廓、克制阴影。
- Web 文章插画解释核心知识点；原生课程插画表现单个动作或步骤。
- 图片内部不生成文字，说明文案继续由 UIKit 或 HTML 渲染，保证中英文切换和可访问性。
- 安全相关内容只表现正确做法，不以危险动作作为视觉焦点。

## 资源命名与目录

每篇资料使用稳定的 `key` 生成两个资源名：

- 写实封面：`learn-<key>-photo`
- 教学插画：`learn-<key>-illustration`

资源放入 `CoastWild/Resources/Assets.xcassets`，每个资源使用独立 `.imageset`。写实封面保存为优化 JPEG；教学插画保存为优化 PNG。单张目标体积控制在 900 KB 以内，整套新增资源目标控制在 55 MB 以内。

## 数据映射

- `heroImage` 指向 `learn-<key>-photo`。
- Web 详情的主要 `image` 内容块指向 `learn-<key>-illustration`。
- 原生详情的第一张步骤图指向 `learn-<key>-illustration`；其他步骤继续复用该主题图，直到后续补充更多动作分镜。
- 保留原有 8 张图片供首页、日记和兼容路径使用，不覆盖或删除。

## 生成批次

1. 冲浪：15 张摄影封面 + 15 张教学插画。
2. 徒步：15 张摄影封面 + 15 张教学插画。
3. 露营：15 张摄影封面 + 15 张教学插画。

每个批次检查主题准确性、人物肢体、装备合理性、无文字、色彩一致性和移动端裁切安全区。不合格图片以版本化文件名重新生成，避免覆盖已选资源。

## 验收标准

- 45 篇资料均拥有唯一封面和唯一教学插画引用。
- `catalog.json` 中不存在学习资料继续引用 8 张旧通用图的情况。
- 所有资源名能被 `UIImage(named:)` 正常加载。
- Web 与原生详情均能展示对应插画；缺图时现有占位行为仍然有效。
- JSON 校验、资源完整性测试、Swift 单元测试和 iOS 模拟器构建通过。

## 风险与控制

- 90 张生成图片可能增加安装包体积，因此导入前统一缩放和压缩。
- 生成图片可能出现装备或动作错误，安全类主题需要逐张人工检查。
- AI 图片不承载教学文字或精确数据，所有教学结论继续由结构化正文提供。
