## 功能闭环

学习列表 → 专题预览 → 确认解锁 → 扣除金币 → 完整阅读。

余额不足 → 购买金币 → Apple 支付 → 验证并入账 → 返回原专题 → 用户再次确认解锁。

- 充值不自动消费；重复进入已解锁专题不重复扣款。
- 免费内容保留免费。Unlocked 分段展示已解锁专题，钱包入口跳到同一分段。
- 付款取消、失败不加币；验证未完成保留处理中状态，避免引导重复付款。
- 金币记录显示充值及专题消费；重复交易不重复入账。

## 审批时一起确认的差异与示例

- 数字为独立状态示例：余额100解锁30后剩70；余额10不足30时差20。后者充值100后应为110，解锁后80，不能硬编码成70。
- 商品 1coins_19 暂按100金币；专题暂按30金币。$0.99为旧设计占位，真实价格读取App Store。
- 原三张保留原图：从专题进入购买时，处理中/成功页的 Back to Explore 改为 Back to guide；从普通入口进入则返回原入口。Preview only示例说明不进入正式界面。
- 新弹窗图的暗色背景由生成工具绘制，照片及背景专题文案与详情图有差异。实现时必须复用05专题详情原页面，仅覆盖06/07弹窗，不新增收藏按钮，也不采用背景中的25分钟或2–3小时文案。专题统一4章、20分钟。
- 同一专题的照片实现时统一采用确认后的同一素材；手机外框与状态栏不是应用绘制内容。
- 用户已选择本地钱包。现有充值接口负责订单验证，本地账本负责余额、扣币及解锁；不承诺跨设备或重装恢复。
